# Saucy Pizza Express

Build a modern, mobile-first web app for a pizza chain called 'Pizza Saucy'. The primary color should be a vibrant, appetizing red. The hero section needs a dropdown to select a branch (Ali View Garden or Askari-XI) and a prominent 'Order Now' button. Below that, create an 'Exclusive Deals' section displaying 3 modern, image-based cards (Family Feast, Solo Bite, Midnight Craving) with 'Save 20%' badges and crossed-out pricing. Make the UI look like a premium food delivery app using clean, rounded cards and subtle hover animations.
